# Versión final de Yujin

Esta carpeta contiene el bot sin pruebas automatizadas ni comandos de diagnóstico de prueba.
Las pruebas se conservan en el proyecto de desarrollo y QA.

Instala con `pnpm install --frozen-lockfile` y ejecuta `pnpm start`. Configura las variables de entorno del bot y conserva los datos de tu servidor al actualizar.
